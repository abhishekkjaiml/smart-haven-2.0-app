# smart-haven-2.0-app
🌱 SmartHaven 2.0 — A modern IoT environment monitoring app built with React Native &amp; Expo 📱. Monitor 🌡️ temperature, 💧 humidity, 🌫️ AQI &amp; gas levels in real time with Firebase, Socket.IO and a Render-hosted backend ⚡. Includes 🔐 auth, 🚨 alerts, 📴 demo mode &amp; 🌙 theme support.
